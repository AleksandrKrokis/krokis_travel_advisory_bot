# Travel Advisory Bot: раннее предупреждение для Таллинна

Бесплатный Telegram-бот на GitHub Actions. Каждый час проверяет 12 независимых
источников и предупреждает, если растёт риск военного конфликта вокруг Эстонии,
чтобы можно было уехать **до** начала боевых действий.

## Уровни

| Уровень | Когда | Что делать |
|---|---|---|
| 🟢 СПОКОЙНО | тревожных сигналов нет | — |
| 🟡 НАБЛЮДАТЬ | 1 серьёзный сигнал или 2 слабых из разных источников | следить, проверить документы |
| 🟠 ГОТОВИТЬСЯ | 2 серьёзных сигнала из разных источников | документы, наличные, бак, гибкий билет |
| 🔴 УЕЗЖАТЬ | 1 критический сигнал или 3 МИДа одновременно | уезжать, пока работают паромы и самолёты |

## Источники

| Источник | Что ловит | Как часто |
|---|---|---|
| Госдеп США | уровень по Эстонии и соседям, «ordered/authorized departure» | 1 ч |
| МИД Великобритании (FCDO) | статус «avoid all (but essential) travel» | 1 ч |
| МИД Германии | Reisewarnung и предупреждения о ситуации | 1 ч |
| МИД Канады | уровень advisory | 1 ч |
| Посольство США в Таллинне | предупреждения (alerts) | 1 ч |
| ERR и Postimees (EN/ET/RU) | заголовки: военное положение, мобилизация, нападение, статьи 4 и 5 НАТО, эвакуация посольств, кабели, нарушения воздушного пространства, Нарва | 1 ч |
| Polymarket | вероятность нападения России на страну НАТО или ЕС, применения статьи 5, перемирия в Украине | 1 ч |
| FAA | запрет полётов авиакомпаний США над Эстонией и соседями | 3 ч |
| EASA CZIB | бюллетени о зонах конфликта | 3 ч |
| OpenSky | небо над Эстонией опустело (сравнение с нормой для этого часа) | 1 ч |
| GDELT | всплеск риторики российских СМИ о Прибалтике и военной темы в мировых СМИ | 6 ч |
| Tallink | места и цены на паромы Таллинн → Хельсинки и Таллинн → Стокгольм | 3 ч |

Сигналы от соседей (Латвия, Литва, Финляндия, Польша) весят на одну ступень меньше, чем по Эстонии.

## Как бот избегает шума

- **Первый запуск каждого источника молчит**: он только запоминает текущее состояние.
- Слабые сигналы (🟡) **не присылаются сразу**, они попадают только в сводку.
- Каждый сигнал объявляется один раз. Повторно только если он усилился.
  Сигнал, который пропал и вернулся в течение 72 ч, не объявляется заново.
- Уровень повышается сразу, а **понижается только через 72 ч** без новых сигналов.
- Много сигналов из одного источника (например, 10 новостей) не повышают уровень.
  Нужны разные независимые источники.
- Новость о решении (военное положение, мобилизация, нападение) из одного издания
  помечается «⚠️ Не подтверждено». 🔴 ставится только после подтверждения вторым изданием.
- Сбои источников уходят только в админ-чат и только если источник молчит больше 12 ч.

## Сообщения

- **Сразу**: повышение или понижение уровня, новые 🟠 и 🔴 сигналы. Всё одним сообщением за запуск.
- **Сводка**: по понедельникам около 09:00 по Таллинну, а при уровне 🟡 и выше ежедневно.
- Посмотреть примеры всех сообщений (ничего не отправляется):

```bash
python scripts/preview_messages.py
```

## Настройка

Секреты в **Settings → Secrets and variables → Actions**:

- `TELEGRAM_BOT_TOKEN`: токен от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHAT_ID`: канал или чаты подписчиков, через запятую
- `TELEGRAM_ADMIN_CHAT_ID` (опционально): твой личный чат для технических сообщений о сбоях источников

Состояние хранится в ветке `bot-state`, не в `main`.

## Ручной запуск

**Actions → Check Travel Advisories → Run workflow**. По умолчанию включён `dry_run`:
сообщения печатаются только в лог, в канал ничего не уходит, состояние не меняется.

## Локально

```bash
pip install -r requirements.txt pytest
python -m pytest tests
python check_advisories.py --dry-run --force --state /tmp/state.json
```

Без `TELEGRAM_BOT_TOKEN` бот никогда ничего не отправляет. В Эстонии Polymarket
заблокирован провайдерами, поэтому локально этот источник падает по таймауту.
В GitHub Actions он работает.

## Настройка порогов

- География: `bot/config.py`
- Правила для заголовков: `bot/sources/news.py` (тесты в `tests/test_news_rules.py`)
- Пороги Polymarket: `bot/sources/polymarket.py`
- Правила общего уровня: `compute_level` в `bot/engine.py`
